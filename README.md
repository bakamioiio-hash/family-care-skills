# Family Care Skills (长辈关怀与防骗话术库)

本项目旨在收录和共建一套**真正站在长辈心理视角、温和且有效**的家庭防骗与沟通话术库。

不同于生硬的说教和“千万别买”的指责，本项目主张通过**肯定初衷、拆解套路常识、设立安全延时缓冲**的方式，帮助家庭晚辈优雅化解针对长辈的各类消费陷阱。

## 欢迎共同扩充 (Contributing)

如果您在日常生活中也经历过长辈遭遇各类骗局，或总结出过有效的沟通话术，非常欢迎提交 **Pull Request** 或开 **Issue** 讨论！

### 期待扩充的场景方向
- **线下活动引流**：免费领鸡蛋、量血压、听养生讲座等线下“洗脑”套路。
- **高科技伪概念**：磁疗床垫、量子富氢水机、太赫兹理疗仪等高价设备。
- **政策与情感伪装**：假借“国家扶贫补贴”、“老区助农特产”等名义的销售套路。
- **投资与理财陷阱**：养老原始股、以房养老、高息互助盘等大额金融骗局。

### 内容提交准则 (CRITICAL)
为了保持话术的有效性与温度，新增内容请尽量遵循以下三项原则：
1. **不指责、不否定**：避免使用“您又被骗了”、“这是假的”等激化防御心理的词汇。
2. **不说教、去术语**：杜绝“私域转化”、“信息茧房”等公文词汇，转化为老人听得懂的大白话（如“网上戏班子”、“台词本”）。
3. **有具体台阶**：每条话术必须提供一个具体的“安全刹车动作”（例如：“等晚辈下班查验”、“周末带去大医院挂号”）。

### 贡献步骤
1. Fork 本仓库并新建分支（如 `feature/offline-egg-scam`）。
2. 在 `skills/` 目录下新增或完善 `.md` 文档。
3. 提交 PR，并在描述中简要说明该场景的**核心破绽**与**长辈真实心理**。
